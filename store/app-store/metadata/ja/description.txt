Vstavka はコピーした内容を履歴として保存し、画面下部のパネルにカードで表示します。shift + command + V でパネルを開き、カードを選んで return キーを押すと、その内容がクリップボードに戻ります。あとは command + V で貼り付けられます。

保存される内容
• テキスト、リンク、色、画像、ファイル
• 各カードに内容のプレビューとコピー元のアプリを表示
• 初期設定では過去30日間のうち新しいものから最大500件を保存。保存件数と保存期間は変更できます

すばやく見つける
• 履歴を検索できます
• テキスト、リンク、画像、ファイルのいずれかに絞り込めます
• よく使う項目はピン留めできます。ピン留めした項目は削除するまで保存されます
• 矢印キーでカード間を移動できます。command + 1 から command + 9 で、位置に応じてカードを選べます

履歴はお使いの Mac の中だけに
• 履歴は暗号化してから、お使いの Mac にのみ保存します
• アカウント、広告、利用状況の分析、ネットワーク機能はありません
• パスワード管理アプリは初期設定で除外されています。「除外するアプリ」にはほかのアプリも追加できます
• 残したくない内容をコピーする前に「保存を一時停止」できます。個別の項目の削除や「履歴を消去」もできます

使い方に合わせて設定
• 「設定」でショートカットを変更できます
• ライトとダークのテーマ、アクセントカラーを選べます
• インターフェイスは24言語に対応
• メニューバーから使えます。ログイン時に開くこともできます

知っておきたいこと：テキストは書式なしで保存されます。ファイルのカードにはファイルへのパスが記録されます。貼り付けるときは、ファイルが元の場所にある必要があります。

Vstavka は無料のオープンソースアプリです。サブスクリプションやアプリ内課金はありません。
