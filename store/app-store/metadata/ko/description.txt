Vstavka는 복사한 내용을 기록하고 화면 아래쪽 패널에 카드로 보여 줍니다. Shift-Command-V를 눌러 패널을 열고 카드를 선택한 다음 Return 키를 누르면 해당 항목이 클립보드로 돌아갑니다. 그런 다음 Command-V로 붙여넣으세요.

저장되는 내용
• 텍스트, 링크, 색상, 이미지, 파일
• 각 카드에는 내용의 미리보기가 표시되며, 확인할 수 있는 경우 복사한 앱의 이름도 표시됩니다
• 기본적으로 최근 30일 이내의 항목 중 최신 500개까지 보관합니다. 보관할 항목 수와 기간은 바꿀 수 있습니다

필요한 항목을 빠르게 찾기
• 기록에서 원하는 항목을 검색하세요
• 텍스트, 링크, 이미지, 파일 중 원하는 유형으로 걸러 보세요
• 자주 쓰는 항목을 고정하세요. ‘고정됨’으로 표시된 항목은 직접 삭제할 때까지 보관됩니다
• 화살표 키로 카드 사이를 이동하거나 Command-1부터 Command-9까지의 단축키로 해당 위치의 카드를 선택하세요

기록은 내 Mac에만
• 기록은 암호화한 뒤 Mac에만 저장합니다
• 계정, 광고, 사용 데이터 분석 기능이 없습니다
• 암호 관리 앱은 기본적으로 제외됩니다. ‘제외할 앱’에 다른 앱도 추가할 수 있습니다
• 민감한 내용을 복사하기 전에 ‘저장 일시 중지’를 사용할 수 있습니다. 항목을 하나씩 삭제하거나 ‘기록 지우기’로 전체 기록을 지울 수도 있습니다

내게 맞게 설정하기
• ‘설정’에서 단축키를 변경할 수 있습니다
• 테마는 ‘밝게’와 ‘어둡게’ 중에서, 강조 색상은 원하는 색으로 설정할 수 있습니다
• 인터페이스는 24개 언어를 지원합니다
• 메뉴 막대에서 사용할 수 있으며 로그인할 때 열도록 설정할 수 있습니다

참고: 텍스트는 서식 없이 저장됩니다. 파일 카드는 파일의 경로를 저장하므로 붙여넣으려면 파일이 원래 위치에 있어야 합니다.

Vstavka는 무료 오픈 소스 앱입니다. 구독이나 앱 내 구입이 없습니다.
