# macOS adapter

Construct `MacPlatformServices` on macOS and start the monitor on the Avalonia UI synchronization context. Native clipboard and window operations run on the AppKit main thread. The monitor starts from the current `changeCount` and polls at 300 ms. Later copies supersede earlier ones between ticks. Source name, bundle ID, and icon describe the foreground app at detection time, which can differ from the writer if focus changed. Source icons are rendered in a 32 × 32 bitmap and capped at 64 KiB.

## Clipboard privacy

The monitor skips `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, and `org.nspasteboard.AutoGeneratedType` before reading payloads. It also skips the legacy 1Password marker `com.agilebits.onepassword`, `de.petermaurer.TransientPasteboardType` from TextExpander and Butler, `com.typeit4me.clipping`, and Typinator's `Pasteboard generator type`. [NSPasteboard marker conventions](https://nspasteboard.org/)

With the macOS 15.4 API, background capture requires `AlwaysAllow`. The monitor checks new changes without opening the payload or requesting access in `Default`, `Ask`, or `AlwaysDeny`. The next copy after approval is eligible. Clicking Grant access on the clipboard notice makes one programmatic read of plain text from the general pasteboard and discards the result. This triggers the system access alert and lists Vstavka in Clipboard settings. When access is denied, Open settings opens Privacy & Security → Clipboard. The panel refreshes notices on open, on activation, and shortly after either action. [Apple's pasteboard access modes](https://developer.apple.com/documentation/appkit/nspasteboard/accessbehavior-swift.enum/default?language=objc)

The adapter prefers file URLs, then PNG or TIFF, then URL and plain text. Finder file URLs are stored as paths. TIFF is decoded by AppKit and converted to PNG if it fits the pixel and byte limits. The writer prepares representations before taking the clipboard and records the exact count from `clearContents` for suppression. A plain-text replay writes a single string, with newline-separated paths for file entries.

## Hotkey, panel and paste

The shortcuts use the Carbon ANSI V key position. A replacement is registered before releasing the current shortcut. The panel uses the status window level and `canJoinAllSpaces | fullScreenAuxiliary` so a single window can join the active Space, including a full-screen Space. Activation and keyboard focus still depend on the system and the packaged app's activation policy.

Call `CaptureTarget()` before showing the panel and `PasteAsync()` after hiding it and writing the clipboard. The adapter waits up to 500 ms for the retained target app to become frontmost before posting Cmd+V. `RequestPermission()` presents the Accessibility request and is intended for a UI action. Clipboard replay remains available for manual paste.

## History

History data lives under `~/Library/Application Support/Vstavka`. The adapter checks the login Keychain on first use for a generic password with service `io.github.xopoko.Vstavka` and account `history-key`. Successful lookup or creation enables the Core AES-GCM protector. Keychain errors at initialization select in-memory history for the process.

## Diagnostics

The probe reports pasteboard type names and access behavior, Accessibility status, frontmost app identity and icon validity. It registers and immediately releases the default hotkey. It never requests permissions or reads pasteboard payloads.

```text
dotnet run --project tests/Vstavka.Platform.MacOS.Tests
dotnet publish tests/Vstavka.Platform.MacOS.Probe -r osx-arm64 --self-contained -c Release
```
